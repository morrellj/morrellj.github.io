Client data must be saved to this directory and named as ALClientData.csv
When using the documents for the first time you will need to open the documents directly and link them to the spreadsheet

use .bat file to open the relevant Mail Merge document
click Yes to "...run the following SQL command..."
click OK to "File Conversion...Other encoding...Unicode (UTF-8)"

Go to "Mailings" -"Find Recipient" and search for client under surname
"Save" document and Toggle "Preview Results" to update dates

"Finish & Merge" -"Edit Individual Documents" -"Current record" -OK    ...This will create a new document that you can then edit more if needed and will be the final document you keep for the client
Once you have the new final document close the Mail Merge document, do not need to save.


NB the mail merge documents can be used directly without using the .bat files. It will just mean that everytime you replace the spreadsheet you will have to relink it to the maile merged document.
